## NOTE
This project is a work in progress and is not intended for public use. Expect bugs and missing features.

## Requirements
- [Bun](https://bun.sh)
- [Git](https://git-scm.com/downloads)
- [MongoDB](https://www.mongodb.com/try/download/community)
